# 🐾 Tradutor de Pets AI (v2.0 Ultra)

> **Decodifique o que seu cão, gato ou bichinho está pensando ou responda na língua deles!**

Uma aplicação web interativa, leve, divertida e 100% offline para "traduzir" os sons e pensamentos dos seus animais de estimação.

---

## ✨ Novidades da Versão 2.0

- 🐶 **Multi-Espécies**: Traduza cães, gatos, pássaros, roedores e até capivaras!
- 🗣️ **Tradução Inversa (Humano ➔ Pet)**: Digite ou escolha frases humanas e converta para fonética canina/felina com efeitos sonoros e dicas de linguagem corporal.
- 🎵 **Sintetizador de Áudio Web Audio API (Nativo)**: Latidos, miados, apitos de brinquedo e beeps gerados via código em tempo real, sem necessidade de baixar arquivos de som externos.
- 📊 **Métricas Divertidas**: Além da precisão biológica, veja o "Nível de Fome", "Energia de Zoomies" e o "Desejo Oculto" do seu pet.
- 🖼️ **Gerador de Cards para Redes Sociais**: Crie e baixe uma imagem estilizada com a tradução oficial para postar nos Stories do Instagram ou Status do WhatsApp com 1 clique.
- 🔊 **Leitura com Voz Adaptativa**: Usa a API SpeechSynthesis calibrada com tom e ritmo específicos para cada animal.
- 💾 **Histórico com LocalStorage**: Relembre as últimas traduções e escute-as novamente quando quiser.
- 🌙 **Modo Claro / Escuro**: Alternância suave de temas com persistência no navegador.
- 📖 **Dicionário Secreto Animal**: Guia divertido explicando comportamentos reais (zoomies, o olhar de mendigo na mesa, teorema da caixa de papelão, etc.).
- 🔒 **100% Privado**: Todo o áudio do microfone é processado localmente no navegador e nunca é enviado para a internet.

---

## 🚀 Como Executar

Não precisa de nenhuma instalação, Node.js ou servidor externo!

1. Basta dar um duplo clique no arquivo [`Tradutor de Pets.html`](Tradutor%20de%20Pets.html) para abrir diretamente no seu navegador preferido (Google Chrome, Microsoft Edge, Safari, Firefox, Opera, etc.).
2. No celular, você também pode abrir o arquivo diretamente no navegador para uma experiência mobile perfeita.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico**: Estrutura acessível com suporte a leitores de tela e navegação por teclado (`aria-live`, `aria-pressed`, `role="tab"`).
- **CSS3 Moderno**: Variáveis CSS, Grid, Flexbox, transições dinâmicas, animações fluidas e suporte nativo a Dark Mode (`prefers-color-scheme`).
- **Web Audio API**: Análise de frequências do microfone (`AnalyserNode`) e sintetizador nativo de ondas sonoras (`OscillatorNode`, `GainNode`).
- **HTML5 Canvas**: Visualizador de ondas em tempo real e renderizador de imagens para download em alta resolução.
- **Web Speech API**: Síntese de fala adaptada com entonações personalizadas.
- **LocalStorage API**: Persistência de tema e histórico recente de traduções.
